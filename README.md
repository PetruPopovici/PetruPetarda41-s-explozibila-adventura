# PetruPetarda41-s-explozibila-adventura

A simple browser RPG game has been added to the project.

Files:

- `index.html`
- `styles.css`
- `script.js`

Open `index.html` in a browser to play as Petru Petarda.
Move with WASD or arrow keys, use Space/Enter to explode enemies, and reach Fort Knox to save Big Yahu.
